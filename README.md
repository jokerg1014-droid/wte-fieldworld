# WTE Fieldworld

Interactive, illustrative waste-to-energy supervision sandbox for the Bekasi project discussion. Includes autonomous representative staff, ten accident scenarios, one-click scene selection and a seekable timeline.

Open index.html directly, or publish the main branch root with GitHub Pages. No build step or external runtime requests are needed.

This is a future-operation business demonstration, not an as-built model, operational training procedure, emergency plan or authorization to restart equipment. Project assumptions and references are in the application's About panel. No internal cost workbooks are included in this website.
